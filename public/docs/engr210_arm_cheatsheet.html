ARM Assembly: Quick Reference

Instruction shape · registers · conditions · memory

Compact revision notes for reading basic ARM assembly. Exact syntax and available instructions depend on the target architecture and assembler mode used in class.

1. Registers and operands

General-purpose registers hold operands and intermediate values. The program counter tracks instruction flow; the link register stores a return address for common subroutine calls; the stack pointer identifies the active stack. Register roles and calling conventions depend on the ABI.

MOV   R0, #7       ; immediate value (assembler syntax varies)
ADD   R2, R0, R1   ; R2 = R0 + R1
SUBS  R3, R3, #1   ; subtract and update condition flags

2. Data processing and flags

Arithmetic and logical operations typically read register or immediate operands and write a destination register. Flag-setting forms update condition state such as zero, negative, carry, and overflow. Unsigned carry and signed overflow are different concepts; choose the appropriate condition for the value interpretation.

3. Branching

CMP   R0, R1
BEQ   equal_label     ; branch if comparison indicates equality
B     next_block

A conditional branch reads the flags set by an earlier instruction. Keep the compare and dependent branch together when tracing control flow.

4. Load and store

LDR   R4, [R5]       ; load from address in R5
STR   R4, [R5, #4]    ; store at an offset from R5

Loads move values from memory to a register; stores move register values to memory. Check the operand width, alignment rules, addressing mode, and whether an instruction updates its base register.

5. Trace method

  1. Write initial register and memory values.
  2. Execute one instruction at a time, noting changed registers and flags.
  3. For a branch, evaluate its condition from the latest flags.
  4. For memory access, compute the effective address before reading or writing.
